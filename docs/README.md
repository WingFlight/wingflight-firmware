# Firmware docs

All documentation lives in the [wingflight-docs](https://github.com/WingFlight/wingflight-docs) repository,
published at <https://doc.wingflight.org>: the user guides, the CLI reference, and the developer material under
Contributing (code guidelines, coding style and the
[Technical Reference](https://doc.wingflight.org/contributing/tech/)).

This directory intentionally holds nothing else. Do not add documents here; add them to wingflight-docs and, if
source code depends on one, link to it by URL. See [AGENTS.md](../AGENTS.md) for the working rules.
